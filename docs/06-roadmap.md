# Roadmap

## MVP

1. Phase 0 - Bootstrap repo, docs, monorepo, checks.
2. Phase 1 - Supabase schema, enums, RLS, seed.
3. Phase 2 - Auth, profiles, projects, memberships.
4. Phase 3 - Zones, trades, documents, contract items.
5. Phase 4 - Visits and evidence.
6. Phase 5 - Worker and audio transcription.
7. Phase 6 - Textual AI extraction.
8. Phase 7 - Review workflow and dashboard.
9. Phase 8 - Weekly summary.
10. Phase 9 - Deployment docs.

## Optional Later Integrations

- Telegram gateway.
- NanoClaw gateway.
- Document intelligence.

Optional integrations must stay outside the MVP core unless explicitly approved.
